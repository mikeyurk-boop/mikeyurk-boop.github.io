MICHAEL 3D PRINTING — WEBSITE STARTER

Files:
- index.html: the complete website

Before publishing:
1. Open index.html in a browser to preview it.
2. In the Custom Orders section, replace the seller email placeholder with the email address you want customers to use.
3. Check the sample product names and starting prices; change them to match what you actually offer.
4. This is a starter catalog and quote-request site. It does not process payments or automatically store orders.

To publish:
- Upload index.html (or this whole folder) to a static hosting service such as Netlify.
